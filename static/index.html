How the driver behaviour analyser works

The browser reads motion data from the phone's accelerometer and gyroscope. When location permission and GPS speed are available, speed changes are included as an additional feature. The server analyses each short window with a machine-learning model and returns a prototype behaviour estimate.

This is an academic demonstration. Predictions can be affected by phone orientation, mounting, sensor quality and GPS availability. Some events may produce similar readings, so results require validation with safely collected, independently labelled driving data.

Academic prototype · Not a certified driver-safety or accident-detection system.
